# Hanger Hustle

A small, single-page **vintage resale inventory helper**: photograph pieces, record details and measurements, generate listing text for Poshmark, eBay, Depop, Vinted, Mercari and Etsy (plus optional Facebook Marketplace and Grailed), track where each item is listed or sold (with "remove from" delist reminders), compare sold comps and fees, and export CSV/JSON backups.

**Privacy: all item data and photos stay on your own device** (in your browser's IndexedDB). If you choose *Sign in with Google*, a backup copy is also saved in a hidden app folder in **your own** Google Drive. There is no other server. See [privacy.html](privacy.html) and [terms.html](terms.html).

It does not post to marketplaces by itself yet; for each site it pre-fills the listing so posting is a few taps.

Install: open the site in Chrome on Android and choose *Install app*, or in Safari on iPhone tap *Share → Add to Home Screen*.
