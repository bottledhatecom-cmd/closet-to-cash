# Closet to Cash

A small, single-page **vintage resale inventory helper**: photograph pieces, record details and measurements, generate copy-paste listing text for Poshmark, eBay, Depop, Vinted and Mercari, track where each item is listed or sold (with "remove from" delist reminders), compare sold comps and fees, and export CSV/JSON backups.

**Privacy: all item data and photos stay on your own device** (in your browser's IndexedDB). There is no server, no account, and nothing is uploaded. This site only serves the app's files. Use *Backup → Full backup (JSON)* regularly, because clearing browser data deletes your inventory.

It does not post to marketplaces automatically; it makes copy-paste listing fast.

Install: open the site in Chrome on Android and choose *Install app*, or in Safari on iPhone tap *Share → Add to Home Screen*.
